# Golden set

Content warning: these files contain insults, slurs, threats and self-harm phrases on purpose. They are test data.

One JSONL file per language. Fields: `id`, `text`, `level` (0-4 per the rubric), `categories`
(list, may be empty), `targeted` (bool), optional `note`. Keep items short and realistic: this is
what comments, danmaku and posts look like, not essays.

Grow it from real misjudgments (issue template *misjudgment*), one line per case, in the language
the text was written in. Hate examples use generic groups on purpose.
